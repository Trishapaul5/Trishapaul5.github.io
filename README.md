# Trisha Paul · Portfolio

Static portfolio site (HTML, CSS, JavaScript). No build step.

Live site: https://trishapaul5.github.io

## Files

- `index.html` – home (hero, about with tabs, projects, research, contact)
- `projects.html` – all projects, with filters and GitHub links
- `style.css` – styles, light and dark themes
- `script.js` – theme toggle, tabs, menu, filters, animations, contact form
- `Trisha_Paul_Resume.pdf` – your resume (the Resume buttons link to it)
- `photo.jpg` – optional, see the comment in `index.html`

## Run locally

Open `index.html` in a browser, or run `python -m http.server` in this folder and visit http://localhost:8000

## Publish with GitHub Pages

1. Create a public repository named exactly `Trishapaul5.github.io`.
2. Put all the files in the repository root.
3. Go to Settings > Pages. Under "Build and deployment" choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. Wait one to two minutes, then open https://trishapaul5.github.io
